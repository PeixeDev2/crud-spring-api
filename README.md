# CRUD Spring API

API REST CRUD de usuários desenvolvida com Java + Spring Boot.

## Tecnologias
- Java
- Spring Boot
- MySQL
- JPA/Hibernate

## Funcionalidades
- Criar usuário
- Listar usuários
- Atualizar usuário
- Deletar usuário

## Rotas
GET /usuarios

POST /usuarios

PUT /usuarios/{id}

DELETE /usuarios/{id}

## Ferramentas utilizadas
- IntelliJ IDEA
- Postman
- DBeaver
